# Tandem — Библия вдвоём

Приложение-сайт (PWA) для чтения Библии с партнёром: общий ритм и **совместная серия**, отчёты с фото и рефлексией,
**подтверждение каждого отчёта и заметки партнёром**, напоминания и вдохновение, памятные дни пары, модуль Библии
(Синодальный, KJV, WEB, AYT). Работает как ссылка на Android и iPhone («Добавить на экран „Домой“»), офлайн-тексты.

* **Данные — только в вашем репозитории GitHub** (приватном): отчёты, фото, заметки лежат файлами, сервера нет.
* Дизайн-код и модуль Библии — из [Melete](https://github.com/veracerkof-debug/melete-app) (GPL-3.0).
* Без аналитики, рекламы, трекеров. Сеть — только `api.github.com` (ваши данные) и свои файлы.

## Быстрый старт (создатель пары)
1. Создать бесплатную **организацию** GitHub и в ней **приватный** репозиторий данных (`tandem-data`).
   Почему организация: fine-grained токен не даёт писать в чужой личный репозиторий, даже коллаборатору.
2. Создать токен (владелец — организация, доступ — только этот репозиторий, **Contents: Read and write**).
3. Открыть сайт → язык, имя, аватар → «Создать пару» → вписать `организация/репозиторий` и токен.
4. Добавить партнёра в репозиторий (право записи) и отправить ему ссылку-приглашение из приложения.
5. Уведомления (по желанию, 5 минут): Профиль → Уведомления — приложение само ведёт по шагам.

Подробно — [docs/setup.md](docs/setup.md). Устройство — [docs/architecture.md](docs/architecture.md).

## Разработка
```
npm install
npm run dev       # сервер разработки (доступен с телефона по Wi-Fi)
npm test          # модульные проверки (серии, данные, очередь записи, уведомления, словари)
npm run build     # сборка в dist/
node tests/e2e/run.mjs   # сквозная проверка в Chromium с фальшивым GitHub (после build)
```
