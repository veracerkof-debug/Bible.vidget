# Решения

## 2026-11-19 — старт
* **Отдельный проект** в репозитории Bible.vidget (не модуль Melete): светское приложение Melete остаётся без сети и аккаунтов. Лицензия — GPL-3.0, как у Melete, из которого взяты дизайн-код и модуль Библии.
* **Данные — приватный репозиторий GitHub, токен у каждого** (ответ автора). Каждый пишет только в свою папку `u/<логин>/` → конфликтов нет.
* **Репозиторий данных — в организации GitHub, не в личном аккаунте.** Fine-grained токен не даёт писать в чужой личный репозиторий (ограничение GitHub: один токен — один владелец ресурсов). В организации у каждого участника свой токен. Запасной путь — classic-токен `repo` (слишком широкий, не рекомендуется).
* **Уведомления — Web Push через GitHub Actions** (ответ автора): без сервера; VAPID-ключи создаёт браузер создателя; на iPhone — только с экрана «Домой».
* **Языки:** ru (Синодальный), en (KJV, WEB), id (AYT). Индонезийского перевода в общественном достоянии нет; AYT — бесплатный для некоммерческого использования с указанием источника.
* **Порядок книг — обычный** (Иакова после Евреям), общий для всех языков, чтобы ключи глав совпадали у партнёров на разных языках. Известное расхождение: нумерация псалмов в Синодальном (по Септуагинте) и в KJV/WEB/AYT различается — ссылка «Пс 23» у партнёров на разных переводах покажет соседние псалмы.
* **Подтверждение:** день засчитывается, когда отчёт подтверждён партнёром; подтверждаются отчёты и заметки.
* **Всё бесплатно** (Pro-блокировок из примера нет). Без маскота. «Закладка/ставка» из примера не делается.
* **Фото необязательно**, отрывок обязателен. Фото сжимается на устройстве (≈ 1080 px, JPEG).
