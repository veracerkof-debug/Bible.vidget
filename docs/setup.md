# Настройка

## 1. Репозиторий данных
Приватный репозиторий в вашем аккаунте. Каждый участник пишет **только в свою папку** `u/<id>/` (поэтому конфликтов слияния нет),
читает папки обоих. Структура — в начале `src/core/model.js`. Участник — не аккаунт GitHub, а идентификатор, созданный приложением при входе.

## 2. Токен (один на пару)
github.com/settings/personal-access-tokens/new: Repository access — *Only select repositories* → репозиторий данных;
Permissions → *Contents: Read and write*; срок — до года. Приложение показывает готовую ссылку. Токен хранится только на устройствах пары.

## 3. Приглашение
Профиль (или экран после создания пары) → ссылка-приглашение вида `…/#/join/<владелец>/<репозиторий>/<токен>`.
Токен стоит после «#»: браузер не отправляет эту часть на сервер, а приложение сразу убирает её из адреса.
* **Отправлять только партнёру.** Ссылка = доступ к данным пары.
* **Новое устройство** (свой телефон после сброса, второй телефон): открыть ту же ссылку; когда в паре уже двое, приложение спросит, кто это, и подключит как существующего участника.
* **Ссылка утекла / токен истёк:** создать новый токен → Профиль → Данные → «Новый токен» → отправить партнёру новую ссылку (она, открытая на подключённом устройстве, сама заменит токен).

## 4. Сайт
Fork/клон этого репозитория → Settings → Pages → Source: *GitHub Actions* → push в `main` публикует сайт
(`.github/workflows/pages.yml`). Адрес вида `https://<владелец>.github.io/<репозиторий>/`.

## 5. Уведомления (Web Push через GitHub Actions)
Сервера нет: отправляет workflow в репозитории данных (`data-template/notify.yml`).
1. Профиль → Уведомления → «Создать ключи» (ключ VAPID создаётся в браузере; публичный уходит в `couple.json`).
2. Создать секрет репозитория `VAPID_PRIVATE` со значением закрытого ключа (ссылка в приложении).
3. Добавить `.github/workflows/notify.yml` (ссылка в приложении открывает GitHub с готовым содержимым).
4. Каждый включает уведомления на своём устройстве.

Что приходит: отчёт партнёра («нужно подтверждение»), подтверждение, «пора читать», стих, молитва, заметка, сообщение,
напоминание в выбранный час (по часовому поясу получателя, если отчёта нет), памятный день в 8 утра.
* Workflow берёт скрипт из публичного репозитория приложения (`veracerkof-debug/Bible.vidget`, папка `tools`). При форке — поменять `repository:` в `notify.yml`.
* **iPhone:** Web Push работает только если сайт добавлен на экран «Домой» (iOS 16.4+).
* Расписание GitHub неточное: напоминание может прийти с опозданием до получаса; если расписание сдвинулось в другой час — в этот день пропустится.
* Бесплатного лимита Actions хватает (≈ 720 коротких запусков в месяц).
