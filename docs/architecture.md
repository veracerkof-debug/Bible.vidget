# Устройство

**Стек:** Vite + чистый JavaScript (как Melete), без фреймворка; PWA (манифест, сервис-воркер); тесты Vitest; e2e Playwright.

## Слои
* `src/core` — без DOM: `canon.js` (книги, ссылки, переводы), `bible.js` (загрузка текстов `public/bible/<перевод>/<КОД>.json`),
  `streak.js` и `model.js` (серии и вся производная модель из файлов), `gh.js` (GitHub REST), `repo.js` (локальная копия + очередь записи),
  `kv.js` (IndexedDB), `push.js`/`vapid.js` (Web Push на устройстве), `image.js` (сжатие фото на устройстве).
* `src/app.js` — состояние и все действия пользователя; экраны только показывают и вызывают их.
* `src/screens` — home, word (Библия), chat (лента), history, me (профиль/настройки), checkin, passage, notifs, anniv, onboarding.
* `tools/notify*.mjs` — серверная часть уведомлений (запускается в Actions репозитория данных).

## Данные (в репозитории данных)
```
couple.json                создаётся один раз: id, создатель, vapid.pub
u/<логин>/profile.json     имя, язык, цвет, аватар, часовой пояс, напоминание
u/<логин>/c/<дата>.json    отчёт дня (проход, рефлексия, фото)         u/<логин>/p/<дата>.jpg
u/<логин>/a/<ключ>.json    подтверждение отчёта (c-<дата>) или заметки (e-<id>) партнёра
u/<логин>/e/<id>.json      события: msg, nudge, verse, prayer, note, anniv, anniv-del
u/<логин>/hl.json          выделенные стихи      u/<логин>/push.json  подписки на уведомления
```
**Каждый пишет только в свою папку → конфликтов нет.** Подтверждение — файл в папке подтверждающего.

## Серии
День засчитан у участника, если есть его отчёт **и** партнёр его подтвердил. Совместная серия — подряд идущие дни, засчитанные у обоих;
сегодняшний день серию не рвёт, пока не закончился. Неделя «сохранена», если совместных дней ≥ цели (по умолчанию 5). Дата — по часовому поясу автора отчёта.

## Надёжность
* Запись никогда не теряется молча: сразу в локальную копию и в очередь в IndexedDB; нет сети — уходит позже, при перезапуске тоже; фото всегда раньше отчёта.
* Чтение: одно дерево файлов на синхронизацию (ETag — повтор бесплатный), скачиваются только изменившиеся файлы.
* Конфликт 409/422 при записи → свежее дерево и повтор (до 3 раз).
* Приложение и тексты Библии работают офлайн (сервис-воркер).
